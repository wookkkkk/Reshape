## 1. 产品定位与核心价值主张

### 1.1 产品定位
Reshape 是一款专为**严肃力量训练者与健美进阶爱好者**打造的「极简、高耐用度、高科学性」周期性训练与记录工具。

### 1.2 核心价值主张 (Value Proposition)
1. **彻底告别无脑加重与疲劳透支**：以 **凯谭经典三分化 (Push / Pull / Legs)** 为基准框架，深度内嵌 **RPE 8 疲劳度管理**、**8 次渐进超负荷递进模型** 与 **肌群超量恢复科学**；
2. **现实生活全自适应 (Real-World Adaptive)**：拒绝理想化线性教条，全面覆盖 **状态疲劳自动降重 10%**、**出差/停训 80% 复训保护** 与 **关节不适一键换无痛安全变式**；
3. **极度顺手的健身房实战交互**：专为手汗、心率飙升、大脑缺氧场景设计的 **悬浮休息仓 (±15s)**、**大按键 9 宫格直输键盘**、**彩色杠铃装片免算盘**、**晚高峰器械避让调换** 与 **单侧弱侧平衡对齐**。

## 4. 核心计算公式与算法模型规范

### 4.1 Brzycki 1RM 极限推算与 RPE 储备修正公式
针对用户填写的做组重量 $w$、完成次数 $r$（推荐 $r \le 10$）与主观疲劳度 $\text{RPE}$：
1. **基础 Brzycki 方程**：
   $$1\text{RM}_{\text{base}} = \frac{w}{1.0278 - 0.0278 \times r}$$
2. **结合 RPE 余量（RIR）的高精度修正方程**：
   在真实力量训练中，若做组 @ RPE 8，代表具有 2 次储备余量（$\text{RIR} = 10 - \text{RPE}$），真实极限次数为 $r_{\text{eff}} = r + (10 - \text{RPE})$：
   $$1\text{RM}_{\text{accurate}} = \frac{w}{1.0278 - 0.0278 \times (r + 10 - \text{RPE})}$$
*注：推算结果一律四舍五入取整至最近的 $2.5\text{ kg}$ 步长。*

### 4.2 智能建议起始重量折算矩阵
$$W_{\text{suggest}} = 1\text{RM}_{\text{main}} \times \text{Ratio}_{\text{exercise}} \times \text{RPE\_Factor}$$
- **杠铃卧推**：$1\text{RM}_{\text{bench}} \times 0.65$
- **对握高位下拉**：$1\text{RM}_{\text{deadlift}} \times 0.70$
- **颈前深蹲**：$1\text{RM}_{\text{squat}} \times 0.46$
- **罗马尼亚硬拉**：$1\text{RM}_{\text{deadlift}} \times 0.78$
- **哑铃动作**：计算结果自动除以 2 并在 UI 明确标注 `单手重量 (kg/只)`。
- **自重与加重自重动作 (Bodyweight & Weighted)**：
  - **双杠臂屈伸**：总做功负荷 $W_{\text{total}} = W_{\text{body}} \times 0.9 + W_{\text{extra}}$，起始基准外加配重 $W_{\text{extra}} = \max(0, 1\text{RM}_{\text{bench}} \times 0.60 - W_{\text{body}})$。初始建议配重由 0kg 开始，每阶段以 $+2.5\text{kg}$ 线性加负重；
  - **山羊挺身**：起始负重 $W_{\text{extra}} = 1\text{RM}_{\text{deadlift}} \times 0.25 \times 0.65$（四舍五入至 $2.5\text{kg}$），用户可选择徒手自重做组或抱片负重。

### 4.3 DOTS 力量系数公式 (男女双标准多项式)
DOTS（国际力量举通用评分系数）通过四次多项式精准消除男女生理与体重差异，评分跨性别完全归一化可比：

$$\text{DOTS} = S \times \frac{500}{a_0 + a_1 B + a_2 B^2 + a_3 B^3 + a_4 B^4}$$

其中 $S$ 为三大项总和 (kg)，$B$ 为当前体重 (kg)，多项式多项参数定义如下：

| 多项式系数 | 男性参数 (Male) | 女性参数 (Female) |
| :--- | :--- | :--- |
| **$a_0$** | `-307.75076` | `-57.96288` |
| **$a_1$** | `24.0900756` | `13.6175032` |
| **$a_2$** | `-0.1918759221` | `-0.1126655495` |
| **$a_3$** | `0.0007391293` | `0.0005158568` |
| **$a_4$** | `-0.000001093` | `-0.0000010706` |

**力量评级统一分值矩阵 (跨性别通用)**：
- **新手 (Novice)**：DOTS < 200 分（男: 0.8x/1.0x/1.3x · 女: 0.5x/0.8x/1.0x）
- **初级 (Intermediate)**：DOTS 200–275 分（男: 1.0x/1.3x/1.7x · 女: 0.7x/1.0x/1.3x）
- **进阶 (Advanced ★)**：DOTS 275–350 分（男: 1.2x/1.6x/2.0x · 女: 0.9x/1.3x/1.6x）
- **精英 (Elite)**：DOTS 350–425 分（男: 1.5x/2.0x/2.5x · 女: 1.1x/1.6x/2.0x）
- **大师 (Master)**：DOTS > 425 分（竞技健力选手水平）

### 4.4 彩色杠铃装配与商业铁馆片库过滤算法 (Olympic Plate Loading Algorithm)
给定目标杠铃总重 $W_{\text{target}}$、杠铃杆净重 $W_{\text{bar}}$（`20kg` 男标杆 / `15kg` 女杆与短杆 / `0kg` 史密斯平衡滑块与自重）：
1. 单边目标配重 $W_{\text{side}} = \frac{W_{\text{target}} - W_{\text{bar}}}{2}$；
2. 贪心扣减标准奥赛片与微调片集合 $P = \{25\text{kg(红)}, 20\text{kg(蓝)}, 15\text{kg(黄)}, 10\text{kg(绿)}, 5\text{kg(白)}, 2.5\text{kg(黑)}, 1.25\text{kg(小微片)}, 0.5\text{kg(微加重片)}\}$；
3. **商业健身房通用模式**：支持按国内铁馆主流四种规格 $P_{\text{comm}} = \{20\text{kg(蓝)}, 10\text{kg(绿)}, 5\text{kg(白)}, 2.5\text{kg(黑)}\}$ 进行免 15kg/免微片精准排布；
4. 输出由大到小的单边最少片数装载序列及可视化色标方案。

### 4.5 业务一致性与容错规则
1. **波浪负荷计算规则**：针对 `15/12/10/8` 等波浪推进动作，系统支持在动作配置中按目标次数区间（而非单一首组数字）分别计算各组 RPE 8 对应的建议重量。
2. **未关联 1RM 动作策略**：未关联三大项的动作，系统不强制折算，直接沿用初始设定值与上次做组记录，以固定重量推进。
3. **动作顺序调换一致性**：晚高峰调换动作次序时，会话数据按真实时间戳存储，但周期归档强绑定动作 ID，递进柱状图不受顺序影响。
4. **单侧与双侧录入标准**：
   - 哑铃侧平举、哑铃斜板弯举等双手同时做动作，界面采用单值录入，容量计算为：$\text{Volume} = \text{Weight}_{\text{single}} \times 2 \times \text{Reps}$；
   - 保加利亚单腿蹲、单手下拉等严格单侧交替动作，采用左右独立录入并以弱侧次数锁定 PR 判定。
5. **有效训练容量 (Effective Volume) 计算标准**：
   - **热身组隔离**：热身组（`isWarmup: true`）**严格不计入**月度总吨位与单次战报总容量，防止热身垃圾容量扭曲疲劳评估；
   - **自重做功折算**：针对 `LoadType.BODYWEIGHT`（双杠臂屈伸、引体向上、山羊挺身等），系统结合训练者体重折算机械做功负荷（双杠/引体 $\text{Weight} = W_{\text{body}} \times 1.0 + W_{\text{extra}}$；山羊挺身 $\text{Weight} = W_{\text{body}} \times 0.5 + W_{\text{extra}}$），彻底消除 $0\text{kg}$ 容量导致的超量恢复误判。
6. **练中草稿秒级落盘与异常中断自愈 (Session Draft & Crash Recovery)**：
   - **全会话秒级落盘**：记录页每完成一组打卡，客户端状态即时将整场训练所有动作状态持久化至 SQLite / LocalState 草稿槽；
   - **自愈恢复**：若遭遇意外杀后台、电量耗尽或来电打断，重新进入 App 时，顶部自动高亮显示 `[ ⚠️ 检测到未完成的训练现场 · 点击一键恢复做组数据 › ]`，100% 恢复中断现场。
7. **超级组 (Superset) 穿插休息计时流转规则**：
   - 当两个动作为绑定超级组时（如仰卧臂屈伸 + Y字侧平举），动作 A 完成后组间休息倒计时设为 0 秒并自动切入动作 B 界面；
   - 动作 B 完成后，触发完整的动作组间休息（如 60s/90s），之后切回动作 A 开始下一轮循环。

### 4.6 基于三大项 1RM 自动设定全动作初始重量与波浪逐组递增模型

#### 1. 核心基准 1RM 与全动作生物力学换算公式体系
三大基础复合项作为全站力量换算基准（由用户个人档案提供）：
* **卧推基准 1RM**：$\text{1RM}_{\text{bench}}$（默认 $70.0\,\text{kg}$）
* **深蹲基准 1RM**：$\text{1RM}_{\text{squat}}$（默认 $90.0\,\text{kg}$）
* **硬拉基准 1RM**：$\text{1RM}_{\text{deadlift}}$（默认 $120.0\,\text{kg}$）

针对任意动作 $i$，其估算等效 1RM 为：
$$\text{Estimated 1RM}_i = \text{Base 1RM}_{\text{related}} \times \text{Ratio}_i$$

结合目标做组次数 $\text{Reps}_i$，其初始建议做组重量按 PRD 4.1 Brzycki 力量衰减方程推算：
$$\text{Initial Weight}_i = \text{Round}_{2.5}\Big(\text{Estimated 1RM}_i \times (1.0278 - 0.0278 \times \text{Reps}_i)\Big)$$

#### 2. 波浪负荷逐组单调递增推导规则 (Ascending Wave Model)
针对波浪/金字塔序列（如 `15/12/10/8`）：
1. **单调递增性**：次数递减时（$15 \to 12 \to 10 \to 8$），每组重量必须严格单调递增：$\text{Weight}_1 < \text{Weight}_2 < \text{Weight}_3 < \text{Weight}_4$；
2. **防平梯保障**：对第 $k$ 组（目标次数 $R_k < R_{k-1}$），采用 $W_k = \text{Max}\Big(W_{k-1} + 2.5\,\text{kg},\, \text{Round}_{2.5}(\text{BrzyckiWeight}(1\text{RM}, R_k))\Big)$，彻底杜绝相邻两组四舍五入后重量相同；
3. **首组锚定**：若用户指定了首组重量，系统以首组反推当前状态下的等效做组 1RM，平滑推导后续各组重量，并持久化到计划配置中。

### 4.7 肌肉超量恢复与疲劳代谢动力学生物算法
（详细数学公式推导与生理学机制详见专门规范文档：[SUPERCOMPENSATION_MODEL.md](file:///d:/workspace/Reshape/design/SUPERCOMPENSATION_MODEL.md)）

1. **理论基石（Fitness-Fatigue & MPS 动力学）**：
   - 训练后局部肌群蛋白合成（MPS）窗口在 24~48h 处于高峰，肌糖原超量储备在 60~72h 达到峰值，力量超越原始基准线。
2. **分阶段状态方程**：
   - 0~12h 急性疲劳期 (20%~40%) ➔ 12~36h 组织修复期 (40%~75%) ➔ 36~60h 基线恢复期 (75%~95%) ➔ 60~96h **🔥 超量恢复黄金期 (100% 最佳做组时机)** ➔ >96h 刺激衰退期 (95%)。
3. **容量与负荷加权修正 ($k_{\text{load}}$)**：
   - 超大容量日（Tonnage > 8,000kg）$k_{\text{load}} = 1.25$；主动减载周 $k_{\text{load}} = 0.75$；
   - 肌群异构半衰期：推/拉中型肌群基准 60h，腿部大肌群与神经消耗基准 72h。
### 4.8 全量动作库、自定义动作与无痛变式图谱体系

为了支撑训练者的个性化动作编排与运动损伤康复需求，Reshape 构建了由 **官方黄金动作库** + **用户自定义动作** + **生物力学无痛变式图谱** 组成的动作基础设施：

   - **1RM 关联系数 (`related1RmKey` / `ratioOf1Rm`)**：用于从三大项 1RM 自动折算建议做组重量。

2. **动作编排与选择器交互规范**：
   - 在「计划编排页（`plan-edit.html`）」点击 `+ 添加动作` 或点击动作卡片的 `替换` 时，唤起全量动作库选择器；
   - 支持按部位（胸、背、腿、肩、二头、三头、核心）和器械类型过滤；
   - 支持直接从动作库中一键添加或调起 `+ 新建自定义动作` 模态弹窗。

3. **生物力学无痛变式图谱 (`PainFreeVariantRule`)**：
   - 针对常见的运动损伤与关节疼痛痛点（如卧推肩痛、深蹲膝痛、硬拉腰酸），建立权威的**动作替代映射图谱**：
     - **卧推肩峰痛 / 肩袖不适** ➔ 推荐 `哑铃对握地板卧推`（限制肩关节过度超伸）或 `坐姿器械推胸`；
     - **双杠臂屈伸肩前束牵拉痛** ➔ 推荐 `坐姿器械推胸` 或 `哑铃对握地板卧推`（消除底端超伸与前移）；
     - **侧平举肩峰撞击痛 (SIS)** ➔ 推荐 `上斜胸托哑铃侧平举`（消除肩峰挤压夹角）或 `低位绳索侧平举`（全程恒定平稳张力）；
     - **深蹲膝关节剪切痛 / 髌腱炎** ➔ 推荐 `保加利亚单腿蹲`（腰椎零轴向压迫，弱化膝前侧剪切力）或 `45度倒蹬机/坐姿腿屈伸`；
     - **硬拉腰椎下背酸胀** ➔ 推荐 `罗马尼亚硬拉 (RDL)`（专注纯髋铰链模式）或 `山羊挺身 (后链强化)`；
     - **高位下拉肘腕不适** ➔ 推荐 `宽握转中立对握高位下拉`（消除前臂旋前扭矩）；
   - 在训练记录页（`record-v2.html`）与动作详情页，点击「🛡️ 关节友好变式」抽屉时，系统基于图谱实时输出针对受保护关节的替代方案与换算重量。
